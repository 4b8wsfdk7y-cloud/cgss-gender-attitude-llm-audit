# 毕业论文设计

本仓库的第二版实验是作者武汉大学本科毕业论文（2027 届）的经验主体。本页记录论文当前的研究问题、设计和章节结构，并说明各章对应仓库中的哪些脚本和聚合结果。论文正文不在仓库中；CGSS 原始数据、画像和画像层面的模型输出也不在仓库中，见[数据与复现边界](reproducibility-boundary.md)。

本页随论文写作更新，最近一次更新为 2026 年 11 月（开题阶段）。

## 题目

**生成式人工智能用于社会调查的适用边界：大语言模型模拟性别观念作答时对前序回答的过度依赖**

## 研究问题

问卷调查的作答理论认为，受访者前面的回答会成为后面判断的依据。Feldman 和 Lynch（1988）称之为自我生成效度，共同方法偏差研究也把一致性动机列为偏差来源（Podsakoff et al., 2003）。论文在大语言模型扮演受访者的场景中检验这一机制。

CGSS 的五道性别观念题提供了形态清楚的人类参照：前四题（A421—A424，涉及社会分工与能力）彼此相关，第五题（A425，夫妻应该均等分摊家务）几乎不随前四题变化。模拟受访者只有再现 A425 与前四题的脱节，才算还原了这一结构。

论文回答四个问题：

1. 真实受访者在这五道题上呈现什么样的题项结构和群体差异；
2. 大语言模型模拟同样背景的受访者时，能否再现这一结构；
3. 偏差来自作答过程的哪个环节，模型对前序回答的依赖是否超出这些回答本身包含的信息；
4. 哪些做法可以降低偏差，代价是什么，政府部门和研究机构在调查工作中使用模拟受访者之前应检验哪些性质。

理论预期：依据自我生成效度，模型看到前序回答后，题项间一致性会提高。如果这是对信息的合理利用，提高幅度应与统计模型获得同样信息时相当；超出这一幅度的部分记为过度依赖。

论文的理论来源是社会心理学的调查作答研究，经验材料来自性别观念研究，应用落点是公共管理中的数智治理，即在问卷预测试、量表开发和模拟调查中使用大语言模型之前需要做的检验。

## 研究设计

| 环节 | 做法 |
|---|---|
| 人类基准 | CGSS 2012、2018、2021 的 A421—A425；加权相关、有序单因子模型（WLSMV）、等级反应模型；按题目估计教育、城乡和性别的系数 |
| 画像 | 三轮各抽 100 名受访者，共 300 个只含人口学信息的匹配画像 |
| 模型 | Qwen3.5-9B（4 比特量化，关闭思考模式）；Gemma 4 12B 作跨模型复制；均在本地运行 |
| 测量方式 | 每次前向计算直接读取五个选项的概率，不从抽样文本推断 |
| 析因设计 | 2×2×2 完全析因：题组是否同时可见（A）、是否提供前面题目的回答（B）、是否要求 JSON 输出（C） |
| 主要指标 | A425 期望得分与前四题期望得分的平均绝对相关；另报告题目均值误差、对数得分和排序概率得分 |
| 画像层面基准 | 只使用人口学信息、用 CGSS 训练的梯度提升模型（HGB），用于区分画像信息不足与作答过程造成的偏差 |
| 推断 | 按画像聚类的自助法（2,000 次）给出效应和 95% 区间 |
| 预注册 | 主要分析于 2026 年 10 月 13 日预注册；追加分析在运行前补写条目，作为探索性结果报告，见 [`PREREGISTRATION_V2.md`](../PREREGISTRATION_V2.md) |

## 前期主要结果

| 分析 | 指标 | 结果 |
|---|---|---|
| 人类基准（CGSS 2012、2018、2021） | A425 与前四题均值的相关；有序单因子模型的标准化载荷 | 相关 0.05—0.10；A425 载荷 0.16，其余四题 0.55—0.77 |
| 主实验（Qwen3.5-9B，2×2×2 析因） | A425 与前四题期望得分的平均绝对相关 | 无作答历史的四个条件 0.39—0.58；有作答历史的四个条件 0.78—0.92；HGB 基准 0.45 |
| 作答历史的主效应 | 效应估计及 95% 区间 | +0.379 [0.339, 0.410] |
| 抽样作答历史 | 作答历史的主效应 | +0.309 [0.271, 0.338] |
| 思考模式（第一版提示词） | 平均绝对相关 | 关闭 0.91，开启 0.44 |
| 个体预测 | 对数得分（越低越好） | 全部条件为 1.97—3.06，均差于五个选项等概率猜测（1.61） |
| 群体差异 | 城镇居住对 A425 的系数 | 8 个条件中有 7 个为 0.21—0.88；CGSS 为 0.01 |
| 真人作答历史 | A425 对前四题均值的斜率 | 模型 0.55—0.65；CGSS 0.11；获得同样历史的 HGB 约 0.09 |
| 少量真人校准 | 题目均值误差；A425 的性别差距 | 只加类别偏移时，100 个真人回答可使均值误差降至 0.13—0.15，结构偏差基本不变；同时调整温度后结构偏差消失，A425 的性别差距由 CGSS 的 0.30 降至 0.02—0.15 |
| 题序探针 | CGSS 题序在 120 种排列中的排名 | CGSS 标题下第 85 位，中性标题下第 23 位；正面对照第 1 位 |
| 下游统计 | 删去 A425 后 α 上升；A425 达到保留标准（校正题总相关 ≥ 0.30 且载荷 ≥ 0.40） | CGSS 同等样本量 1,000 次抽样：α 上升 999 次，达到标准 0 次；有作答历史的四个条件共 20 个数据集：α 上升 0 个，达到标准 20 个 |
| 跨模型复制（Gemma 4 12B） | 平均绝对相关；作答历史的主效应 | 无作答历史 0.40—0.60，有作答历史 0.65—0.83；+0.260 [0.231, 0.284] |

第 2、3 行为预注册主要估计量；其余为追加分析，作为探索性结果报告。

三点主要结论：没有作答历史时，模拟受访者的一致性与 HGB 基准相当，提供作答历史后明显升高；给定真实作答历史时，模型的斜率仍远高于 CGSS 和获得同样信息的 HGB；依据有作答历史的模拟数据，研究者会把 A425 保留在量表中，与依据真实数据得出的题项筛选结论相反。

## 待完成工作

## 局限

- 结果只来自两个 4 比特量化的本地模型，结论限定在所用模型和设置内；
- A425 只有一道题，措辞方向与前四题相反。人类基准的作用是给出真实的相关结构，论文不依赖对 A425 脱节成因的判断；
- 追加分析在预注册结果已知后设定，论文中与预注册分析分开报告。
